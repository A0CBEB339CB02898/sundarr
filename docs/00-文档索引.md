# Sundarr 文档索引

本文档是 `docs/` 的唯一导航入口。文档按“一个主题、一个事实源”维护；阶段过程、测试快照和一次性实施记录不再长期保留在 `docs/`，需要追溯时使用 Git 历史。

更新时间：2026-08-30。

## 当前状态

- Phase 0—10.2 已完成，其中 Phase 10.2 仅代表媒体发现 Core 结构性收口。
- 当前阶段是 Phase 10.3：在外部官方仓库交付真实插件，并用真实数据持续回归 Core。
- 插件顺序：TMDb 目录 → SeedHub SOURCE 迁移与回归 → 豆瓣目录 → 豆瓣想看。
- 首个 TMDb 端到端通过并修正通用合同后，冻结 Plugin API v2。
- 真实 SMB 来源到目标的完整同步仍是 MVP 发布前的手动验收门。

## 维护规则

1. 产品范围只写入 `01`，路线状态只写入 `03`，插件运行语义只写入 `14`。
2. 其他文档引用事实源，不复制整段状态或路线图。
3. 已完成的一次性实施过程不新增永久文档；提交信息和 Git diff 即为历史记录。
4. 测试结果写入 CI、终端输出或发布记录，不在 `docs/` 累积按日期命名的快照。
5. 文件名使用两位序号与简体中文主题名；协议字段、代码标识符和标准缩写可保留英文。
