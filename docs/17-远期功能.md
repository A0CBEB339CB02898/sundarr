# 远期功能

本文档只记录没有进入近期路线的方向。保存到网盘、统一传输驱动、网盘直链和 qBittorrent 已于 2026-09-21 提升到 Phase 10.6—10.9，其实施事实源改为 `03-开发路线图.md`、`05-媒体库同步与传输.md` 和 `14-插件系统.md`。

更新时间：2026-09-21。

## 1. 已移出本文件的方向

以下能力已排期，不再属于未排期远期功能：

```text
Phase 10.6 保存到网盘
Phase 10.7 统一 TRANSFER_DRIVER 与 SMB 适配
Phase 10.8 网盘直链下载
Phase 10.9 qBittorrent 下载
```

开始实施前至少需要确认：

- 平台接口和认证方式合法、稳定且可维护。
- 凭据加密、脱敏、失效和撤销策略。
- 临时地址有效期、限流、断点续传和校验语义。
- 驱动失败不会破坏现有 SMB 主链路。
- 真实测试不包含绕过会员、验证码或平台限制。

Alist、Aria2 和 rclone 仍不属于当前近期主线。具体网盘 Provider 只有在公开接口、账号条件、凭据安全和真实测试可维护时才进入对应纵向切片。

## 2. 通知插件

`NOTIFICATION` 可以消费 Core 产生的领域事件并向钉钉、飞书等渠道投递。通知失败不得阻塞同步状态机，也不得由插件直接修改任务事实。

## 3. 外部人工智能桥接

Phase 11 之后可以提供 Cordis / DeepSeek Harness 桥接。桥接通过公开 Sundarr HTTP API 工作，不进入 Python PluginActivation 进程，也不访问 ORM Session、SMB 凭据或 Worker 内部对象。
