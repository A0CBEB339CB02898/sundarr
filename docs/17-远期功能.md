# 远期功能

本文档只记录已经讨论但明确不进入 MVP、也没有近期排期的方向。它不是实施承诺，开始开发前必须重新确认产品范围、合法性和安全边界。

更新时间：2026-08-30。

## 1. 网盘直链下载

预研方向是通过受支持平台的公开接口获取文件流或临时下载地址，再由独立搬运驱动写入本地媒体库。它不替代当前“远程媒体库 SMB 扫描并同步”的主链路。

可能的组件：

```text
平台认证连接器
  -> 文件定位与下载地址获取
  -> TRANSFER_DRIVER
  -> 临时文件、续传、校验和原子重命名
```

开始实施前至少需要确认：

- 平台接口和认证方式合法、稳定且可维护。
- 凭据加密、脱敏、失效和撤销策略。
- 临时地址有效期、限流、断点续传和校验语义。
- 驱动失败不会破坏现有 SMB 主链路。
- 真实测试不包含绕过会员、验证码或平台限制。

Alist、Aria2、rclone 和具体国内网盘 Provider 均不属于当前或近期主线。

## 2. 统一搬运驱动

未来可以定义 `TRANSFER_DRIVER`，但顺序必须是：

1. 先让 Core 内置 SMB 实现满足统一合同。
2. 持久化任务所选择的驱动 ID 和版本，保证重试可追踪。
3. 再评估 HTTP、网盘或下载客户端驱动。

qBittorrent、BT、磁力和种子下载当前不进入 MVP。

## 3. 通知插件

`NOTIFICATION` 可以消费 Core 产生的领域事件并向钉钉、飞书等渠道投递。通知失败不得阻塞同步状态机，也不得由插件直接修改任务事实。

## 4. 外部人工智能桥接

Phase 11 之后可以提供 Cordis / DeepSeek Harness 桥接。桥接通过公开 Sundarr HTTP API 工作，不进入 Python PluginActivation 进程，也不访问 ORM Session、SMB 凭据或 Worker 内部对象。
