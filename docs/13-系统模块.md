# 系统模块

本文档描述当前模块职责和数据流，不重复路线状态和详细协议。阶段状态以 [03-开发路线图.md](03-开发路线图.md) 为准。

更新时间：2026-09-14。

## 1. Core 边界

| 模块 | 职责 | 不负责 |
|---|---|---|
| FastAPI API | 参数校验、调用服务、返回统一响应 | 平台专用解析、长期 Worker 循环 |
| 搜索服务 | 并发调用 SOURCE、标准化、去重、收藏标记 | 目录发现、自动创建传输任务 |
| 媒体发现查询编排 | 选择目录 Provider、校验能力、调用、缓存与降级 | 媒体身份合并规则和平台专用解析 |
| 媒体身份服务 | 规范身份、外部 ID、最小快照、关注状态和响应映射 | 调用目录 Provider 或持有 Redis 客户端 |
| 收藏服务 | 持久化用户主动收藏的资源或链接 | 替代实时搜索数据源 |
| 插件宿主 | 仓库准备、Manifest 解析、运行时加载、Activation、Registry、诊断和回滚；各层通过显式对象协作 | 执行不可信代码沙箱、平台业务实现 |
| SMB 与媒体库 | 连接、目录绑定、扫描和安全写入 | 网盘登录、直链提取 |
| Transfer Worker | 运行循环负责调度，配置模块负责运行参数，任务管线负责复制、校验和紧邻成功事务的清理 | 发现媒体或任意改变已持久化驱动选择 |
| PostgreSQL | 业务事实、配置、任务、游标和最小媒体快照 | 缓存完整目录原始响应 |
| Redis | 搜索、目录详情和短期状态缓存 | 唯一业务事实来源 |

## 2. Web Console

现有页面负责状态、发现、具体资源搜索、收藏、任务、SMB 连接、本地媒体库、远程媒体库和搜索源测试。它是控制台，不是播放器、文件管理器或完整本地媒体库 UI。

插件仓库管理 API 与 `/app/plugins` 管理页面均已完成，可管理仓库、锁定 commit、配置、启停和诊断。Web Console 不上传、编辑或保存 Python 代码。

## 3. 外部仓库

```text
sundarr Core
  ├─ 公共合同、Loader、Activation、Registry、业务编排
  ├─ 离线测试替身与 conformance runner
  └─ API / Worker / Web Console

sundarr-sources
  └─ SeedHub 等敏感 SOURCE 插件

sundarr-plugin
  └─ TMDb、豆瓣目录、豆瓣想看等非 SOURCE 官方插件
```

两个官方仓库分别锁定 commit、更新和回滚。Core 继续支持多个用户信任的第三方仓库。

## 4. 主要数据流

### 4.1 媒体发现

```text
用户筛选 / 外部想看同步
  -> CATALOG_PROVIDER / WATCHLIST_PROVIDER
  -> Core 身份归一化
  -> PostgreSQL 最小快照 + Redis 易变详情
  -> /app/discover
```

### 4.2 具体资源搜索

```text
关键词
  -> SOURCE
  -> RawSearchItem
  -> 提取、标准化、去重、排序
  -> 附加收藏标记
  -> 实时返回 ResourceCandidate
```

搜索默认不持久化，也不自动创建任务；只有用户主动收藏时写入 `Resource` / `ResourceLink`。

### 4.3 媒体库同步

```text
远程媒体库扫描
  -> SyncSeenFile
  -> TransferTask / TransferFile
  -> Worker
  -> SmbWriter 写入本地媒体库
  -> 校验、重命名、可选清理来源
```

### 4.4 插件更新

```text
锁定 commit
  -> 解析 Manifest
  -> 准备全部候选 Activation
  -> 配置 / 依赖 / 合同 / 健康检查
  -> 仓库级原子切换
  -> 释放旧 Activation
```

任一必须启用候选失败时不切换 `current_commit`，旧实例继续服务。

## 5. 代码组织边界

- `worker_runtime.py` 只编排常驻循环、插件恢复与定时调度，`worker_config.py` 只读取配置；`worker.py` 保留兼容进程入口和事务密集的单任务执行/清理管线，避免把同一任务成功事务拆散到相互回调的碎片模块。
- 插件 Loader 的 Git 仓库缓存、Manifest 解析和 Python 入口加载互不持有对方的业务状态；Loader 只编排这些能力。
- 媒体发现查询编排只依赖媒体身份服务提供的持久化与响应映射接口，不能再次复制外部 ID 合并规则。
- Web 发现页容器持有导航代次和页面级状态；筛选组件不缓存 API 结果，纯模型模块不发网络请求。

## 6. 当前发布风险

- TMDb、豆瓣补充目录和豆瓣想看均已形成真实数据链；豆瓣仍受非官方公开端点变更和 IP 风控影响，必须保留结构校验、缓存降级和可观测错误。
- SeedHub v2 已从官方 GitHub 仓库锁定 `a10b902`，真实回归和启动恢复均已通过。
- 真实 SMB 单机能力曾人工验证；完整“来源 SMB → 任务 → 目标 SMB → 清理”仍需发布前验收。
- 外部 Python 插件属于信任代码，不是安全沙箱；不可信插件必须另行设计进程或容器隔离。
