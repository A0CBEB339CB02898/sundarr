1. 在smb的目录浏览中，如果目录为/，则输入框中会显示/，但是如果进入了子级目录，则会展示子级目录名，没有/，但如果再次进入子级目录，则输入框中会展示上一级目录的名称，而不是当前目录的名称，例如：当前在/movie目录下，输入框中会显示movie，如果进入了/movie/xxx目录，则输入框中会显示movie/xxx,希望能够一直保持输入框中的/
2. 希望能够在本地媒体库中的对应弹窗中，管理绑定它的远程媒体库。即，能在远程媒体库绑定本地媒体库，也能在本地媒体库绑定远程媒体库。
3. 希望所有地方的表单中，唯一标识都默认不需要手动输入，默认使用UUID自动生成，用户不需要关心这个字段。
4. 在任务页面，不需要展示手动输入的任务ID这个框。用户直接点击交互即可。并且任务页面希望能够自动轮询刷新，轮询间隔为5秒，实时展示任务状态的变化。
5. 在所有模块页面中，都存在一个顶部的大标题、副标题和一个次顶部的大标题和副标题。这个设计过于重复，建议直接保留次顶部区域，删去顶部大标题文字区域。
6. 所有列表查询的页面都默认添加分页功能，默认每页展示20条数据，并且提供分页组件让用户可以切换页码。分页由后端完成。
