## bug 反馈列表

1. 当前绑定关系中，远程movie绑定到本地movie，但是当远程movie扫描到文件时，会同时创建下载到本地movie和本地series的任务
2. 下载到本地的过程中，会产生大的嵌套目录。例如：当前的远程movie下载到本地movie时，会产生/movie/movie/xxx.mkv的目录结构。应该是将远程的目录结构平铺到本地movie目录下，例如/movie/xxx.mkv 导致的。只需要去掉远程目录的一级目录即可，如果媒体本身是带有目录结构的，保持现状 即将目录结构和文件都下载下来
3. 对于媒体文件，存在下载到本地完成后，文件依旧是sundarr.downloading后缀的情况。请检查是否有可能发生这种情况。
4. 任务创建前，应该比对文件的md5，如果本地已经存在同名且md5一致的文件，则直接视为任务完成。
