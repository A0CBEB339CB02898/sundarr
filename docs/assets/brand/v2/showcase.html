Six variants.
One pattern family each.

按 logo-generator-skill 的设计法则重做—— 极致简洁、慷慨留白、精确线宽、单一焦点。每一款来自不同的 pattern family， 而不是同一想法的参数变奏。

Extreme simplicity 每款只有 1–2 个核心元素。 不叠加装饰，不堆符号。
Generous negative space 至少 40% 画布留白。 留白是设计的一部分，不是漏洞。
Structural DNA, not letters 抽取字母的几何本质， 而不是画出完整的 S 或 r。
R · Geometry · Boolean

Intersection

两圆相交，交集区域填实。左圆 Sunday，右圆 *arr， 重叠即 Sundarr 本身。名字构造的几何直译。

P · Dot Matrix · Concentric

Emanation

12 外环点 + 6 内环点，中心留空。 太阳的缺席即其在场。12/6 点位略放大作 r·r 书挡。

S · Radial · Burst

Sunrise

8 道射线交替长短 + 实心核。 最直接的日出符号，不绕弯子。 stroke 3，圆角收尾。

T · Arc · Broken Circle

Cycle

外弧 270° + 内弧 180° + 实心核。 两段弧旋向相反制造张力， 隐喻抓取-处理-同步的循环。

U · Node Network

Topology

三主节点沿对角线分布，两次级节点补张力。 最强不对称构图，隐喻分布式架构： 媒体源 / 存储 / 同步端。

Q · Line System · Masked

Quiet Row

圆内平行线，线宽边缘向中心递增。 y=52 那行刻意空出——Sunday 是一周里 那道静谧的空行。
