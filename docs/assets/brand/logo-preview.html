Sundarr · 品牌标识 v0.3

3 个概念（融合 S + Sunday + 播放）· 3 个应用模式（原 04 / 05 / 08）

这一版做了什么：延续你认可的 02 / 03 方向，把"点"和"内嵌三角"都升级为 太阳（对应 sunday 词根），并把播放三角整合为 太阳的"光芒"之一 —— 三要素（S / Sunday / 播放）共存一体。每张卡底部有 24px / 16px 缩小预览，看看细节在 favicon 尺寸是否还撑得住。

品牌标识候选 v0.3

S + Sunday（太阳）+ 播放三角 —— 三要素共存，差异在"太阳"元素的位置与权重。

A · 日点 S（演进自 02）
角标太阳
保留 02 的"右上角点"构图，把圆点升级为小太阳： 日心 + 3 条线型光芒 + 1 条三角形光芒（即播放 ▶）。 S 本体几乎不动，辨识度与 02 持平，太阳 + 播放融入一个紧凑集合。
Sundar·r Console
B · 晨光 S（演进自 03）
内嵌晨光 · 默认推荐
S 的右上腔里原本内嵌的播放三角，现在换成微型太阳： 空心日 + 3 短光芒 + 1 条三角光芒（播放）。S 仍主导阅读顺序， 上腔里是一颗正在"投光"的微型日。三元素融合程度最高。
Sundar·r Console
C · 朝阳 S（新增）
双要素场景
上半部：完整太阳（日心 + 4 光芒，东方为播放三角）。 下半部：小号 S。读作"朝阳投射 + S"。叙事最强但 16px 下 S 会变小，favicon 可能退化为"纯太阳+播放"（也可接受，因为 Sundarr 尾部 rr 可以挑大梁）。
Sundar·r Console
