Sundarr · 品牌标识 v0.7

彻底修日心与光芒"分离感" · 同时提供 A / B 两款 ☀ 让你选

上一版还像 "1/4 太阳" 的根本原因：v0.6 里光芒 base 在 r=5.05， 而日心只到 r=4.6 —— 中间空了 0.45 单位。所以眼睛看到的不是 "☀"， 而是 "球 + 孤立针"。这一版把 光芒 base 嵌入日心内部，焊成一坨。
同时给 两款风格让你挑 —— 都是"饱满的完整太阳"，视觉气质不同：
  A · 钝三角光芒（emoji ☀ 风格，几何硬）
  B · 圆角棒光芒（天气图标风格，几何软）
选定后 wordmark / 徽章 / favicon 全部统一用这一款。

选 ☀：A 款 or B 款

两款都是"饱满的完整太阳"，base 都嵌入日心，不再是 1/4。

A 款 · 钝三角光芒
日心 r=4.2 + 8 条钝三角光芒，base 宽 4.2 嵌入日心 0.5 单位。 几何硬、比例紧凑，像 emoji ☀ 的简化几何版。徽章尺寸下辨识度最高， 16px favicon 仍能看出 8 芒轮廓。
B 款 · 圆角棒光芒
日心 r=4.4 + 8 条圆角棒光芒（宽 1.8 × 长 3.6，半径 0.9）。 几何软、看起来更友好，接近 Apple Weather 的 sunny 图标。 小尺寸下光芒会细一些，但整体更"温暖"。
