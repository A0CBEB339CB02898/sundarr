4 个 logo 概念（整合 S + 播放器） · 3 个应用模式（原 04 / 05 / 08）

视觉家族：圆角正方形徽章（16px 半径）、粗体单字母、主色 + 奶油白 —— 与 Radarr / Sonarr 的 Servarr 家族同源。 Sundarr 独有：播放三角形以不同强度整合进 "S" 字形， 强度从左到右递增。下方应用模式暂用概念 03占位， 你选完后我会替换成最终 mark。

品牌标识候选

从左到右，S 与播放器的整合强度依次递增。

概念 01 · 纯 S
对照基准
零整合。类 Sonarr 范式，最简洁、工程成本最低。 不包含任何播放元素，靠家族视觉语言暗示。
Sundar·r Console
概念 02 · 指示灯
轻度整合
S 右上角加一颗奶油色圆点，像播放 / 录制指示灯。 S 本体不变形，辨识度与概念 01 持平，符号学上多一层"在运行"的语义。
Sundar·r Console
概念 03 · 内嵌三角
中度整合 · 默认推荐
S 的右上腔体内嵌一个播放三角 ▶，反白描线确保 小尺寸下仍可见。阅读顺序：先识 S、再识 ▶。 兼顾辨识度与叙事，也是下方应用模式占位使用的版本。
Sundar·r Console
概念 04 · 播放尾
重度整合
S 的右下终端变形为向右出挑的播放三角 ▶， 字母与符号融合成单一形体。类 Lidarr 的整合方式， 个性最强，但 16px 以下辨识度可能下降。
Sundar·r Console
