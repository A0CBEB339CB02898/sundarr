Five extensions · NAS × Cloud × Storage
W3-A · NAS BAYS NAS
Sundar·r

NAS Bays · 硬盘托架

4 根竖向圆角长孔，最右一根更高。 Sunday 日轮里挖出 NAS 前面板的硬盘盘位， 最右一根略高 = "一块盘正在工作"。 产品属性最直白。

W3-B · CLOUD Cloud
Sundar·r

Cloud Cutout · 云形切口

一朵云形轮廓从日轮中被挖出。 Sunday 里嵌着一朵云—— 云存储作为 Sunday 媒体的载体。 Cloud 概念最强，但云 icon 比较通用。

W3-C · RAID ARRAY RAIDStorage
Sundar·r

RAID Array · 存储阵列

3×2 规整小方孔网格。 最冷静、最数据感——存储阵列、数据块、 bitmap 都能读出来。Sunday 背后是一套 有秩序的存储系统。工程师友好。

W3-D · HYBRID ORBIT NASCloud
Sundar·r

Hybrid Orbit · 混合云

一大孔（云）+ 一小孔（本地）+ 连接弧。 大小两个负空间 + 一条 terracotta 反向弧 讲同步：本地 NAS 向云端同步。 叙事最完整，Sundarr 场景最贴合。

W3-E · STACK RackStorage
Sundar·r

Stack · 机架堆叠

3 条横向长孔 + 一个活动指示点。 机架里的一层一层存储设备， 中间层最宽，右上角一颗小 terracotta LED = activity indicator。最工业感。
