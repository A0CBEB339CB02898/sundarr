Six canonical archetypes
W1 · RADIAL BURST ref · 282b7bd3

Radial Burst

Sunday 8 rays · alternating lengths · solid core

skill 点名的 Radial Burst 原型的精确复刻：8 道射线从中心辐射， 交替短/长（14 / 22 单位），实心核 r=8。最直接的「Sunday」， 不绕弯子。

skill 说Rhythm through repetition with variation。 重复中加一点变化，比规则重复更有生命力。
Sundar·r
W2 · STAR BURST ref · 009244dc

Star Burst

Sunday rays only · no core · star through absence

同样 8 道射线，但移除中心核。 射线之间留出的星形空白就是 Sunday—— 不画的部分创造了符号。和 W1 是对照实验。

skill 说What you don't draw is as important as what you do. 不画的部分和画的同等重要。
Sundar·r
W3 · PUNCHED DISC ref · 4221df1d

Punched Disc

Sunday Arr solid disc · 4 asymmetric holes

skill 的 Punched Circle 原型：实心大日轮 r=28， 被 4 个不对称圆孔穿透（左上重、右下轻）。 Sunday 和 *arr 目录的 figure-ground 统一—— 日轮和打孔是同一个东西。

skill 说Subtract rather than add. 减法比加法高级。
Sundar·r
W4 · GOOEY NODES ref · b541c30c

Gooey Nodes

Media Arr 2 main · 2 satellite · SVG goo filter

skill 的 Gooey Nodes 原型：两个主节点（r=16 / r=12） + 两颗卫星（r=5 / r=4），用 SVG <filter> 的 goo effect 让它们有机融合。 媒体源流入 *arr 管道的液滴合流状态。

skill 说Use SVG filters (goo effect) for sophistication. 合适的滤镜能把简单形状升格。
Sundar·r
W5 · INFINITY ref · 09b239bb

Infinity Loop

Arr single closed path · stroke 5 · no fill

skill 的 Infinity Loop 原型：单一平滑闭合 bezier 路径， stroke 5，纯轮廓。*arr 自动化的永续循环—— 抓取、同步、入库，无穷无尽。

skill 说One perfect element beats five mediocre ones. 一个完美元素胜过五个平庸元素。
Sundar·r
W6 · PUNCHED RING skill §1.2 arc + §punched

Punched Ring

Sunday Media open ring · Sunday dot at the breach

skill §1.2 Arc Segments + §1.3 Punched 原则的复合： 厚描边环在 12 点方向开一个圆润切口， 一颗实心日轮 r=5 停在那个缺口上—— 媒体容器的环在 Sunday 打开。

skill 说Rounded negative space cuts. 挖的洞必须圆润。
Sundar·r
