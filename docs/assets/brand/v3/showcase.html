Sunday Arr

V1 · Seven Rise

数字 7 的斜笔终点收为一颗太阳。 Sunday 是一周的第 7 天——7 本体即周日， 斜笔终点绽放的圆盘即 Sunday 的到来。 数字「7」自然对接 Servarr 家族里的 第 7 位 *arr 成员身份。

Media Sunday

V2 · Reel Sun

胶片帧上下两排打孔，中间升起一颗半日。 Media 原语（film reel）托起 Sunday 的光—— 把「看一场电影」和「周日早晨的第一道光」 叠合在同一个画面。徽章即胶片，即容器。

Sunday Media Arr

V3 · Weekday

6 根刻度 = 周一到周六，第 7 位 = 带光芒的太阳。 三合一叙事：一周里的节奏（Sunday）、目录里的一行行条目 （Media）、*arr 自动化周末产出的那一刻（Arr）。 左侧克制右侧绽放，不对称张力最强。

Media Sunday

V4 · Horizon

容器里的日出，只剩一个动作。 圆角徽章本体即媒体容器（Servarr 家族 DNA）； 容器内一条地平线 + 半个升起的太阳 + 三道光芒。 figure-ground 统一叙事：媒体容器里藏着周日的光。
